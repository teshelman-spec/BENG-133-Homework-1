# BENG 133 Homework 1

UC San Diego - BENG 133

## Contents
- `BENGHW.py`: Python code for Questions 1, 2, and 3.
- `BENG133_Homework1.pdf`: Written solutions, explanations, and plots.

## Requirements
- Python 3
- NumPy
- Matplotlib

## How to Run
1. Install Python 3 if it is not already installed.
2. Install the required packages by running:

   `python -m pip install numpy matplotlib`

3. Run the script from the terminal:

   `python BENGHW.py`

The script prints numerical results and displays plots for the relevant questions.
